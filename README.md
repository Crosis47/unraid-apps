# Crosis47 Unraid Apps

Unraid Community Applications templates and setup guides maintained by Crosis47.

## Apps

| App | Description | Setup guide |
| --- | --- | --- |
| tModLoader-Web-Managed-Server | A modded Terraria dedicated server with a web dashboard for worlds, Workshop mods, players, settings, and backups. | [tModLoader on Unraid](docs/tmodloader.md) |

Open the **Apps** tab in Unraid and search for **tModLoader** to install
**tModLoader-Web-Managed-Server**.

Container source, releases, and documentation are maintained in
[Crosis47/tmodloader](https://github.com/Crosis47/tmodloader).
For container or tModLoader template issues, use the
[container issue tracker](https://github.com/Crosis47/tmodloader/issues).
